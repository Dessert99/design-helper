# 사용 흐름 모음

대표적인 사용 상황을 시작 조건과 목적에 따라 나눴다. 번호는 문서 식별자이며, 사용자가 순서대로 거쳐야 하는 단계가 아니다.

현재 스킬 지침을 가상 대화로 풀어 쓴 설명 문서다. 예시의 프로젝트 조건과 수치는 설명을 위한 가정이며, 실제 실행 결과나 권장값이 아니다. 각 문서 끝에 행동의 근거를 연결했다.

`축`은 비교할 속성, `표본`은 그 속성값을 적용한 화면의 예시, `사다리`는 한 축의 값을 나란히 펼친 비교를 뜻한다. `스케일`은 프로젝트에서 사용하는 값의 목록이다.
