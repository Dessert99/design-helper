# 06. 이미 확정한 속성의 값을 변경하는 상황

[상황 목록으로](../flows.ko.md)

## 시작 조건

그림자 블러 C 12px를 확정했다. 이전 비교에 B 8px도 남아 있으며, 이후 모서리 값까지 확정한 상태다. 각 선택은 실제 코드에도 반영된 상태다.

## 예시 대화와 스킬 행동

> 사용자: 아까 확정한 블러를 C 12px에서 B 8px로 바꿀게.
>
> 에이전트: 반영·검증 후 보고: 그림자 블러 = B · 8px

메모의 블러 항목을 새 선택으로 덮어쓴다. 이전 표본은 남겨두며 모서리의 확정값은 임의로 바꾸지 않는다. 변경 선택을 코드에도 바로 반영하고 검증한다.

### 변경한 값을 바탕으로 다시 비교하는 경우

> 사용자: 바꾼 블러 위에서 모서리를 다시 비교해줘.

별도 주문을 받은 뒤 블러 8px를 고정하고 모서리 비교를 그린다. 이전 블러 위에서 고른 모서리가 새 블러 위에서도 좋아 보인다고 미리 단정하지 않는다.

## 끝나는 지점

주 흐름은 메모와 코드의 기존 확정값을 바꾸고 검증하는 데서 끝난다. 다른 속성의 재비교는 사용자 주문이 있어야 시작한다.

## 다른 상황과의 차이

[04](04.md)에서는 아직 확정값이 없다. 이 상황은 기록된 결정을 변경한다. `8px가 나은 것 같아`처럼 인상만 말하면 변경 확정으로 해석하지 않는다.
