# 07. 특정 배경을 유지하면서 요소의 속성을 비교하는 상황

[상황 목록으로](../flows.ko.md)

## 시작 조건

기존 카드와 실제로 사용할 황혼 배경 이미지가 있다. 사용자는 그 배경을 유지하면서 카드 **테두리 밝기**를 비교하려 한다. 예시에서는 프로젝트의 불투명한 회색 테두리 후보가 A `#555555` · B `#666666` · C `#777777` · D `#888888` · E `#999999`라고 가정한다.

## 예시 대화와 스킬 행동

> 사용자: 이 황혼 배경은 그대로 두고, 카드 테두리 밝기만 비교해줘.

1. 사용자가 지정한 실제 배경 위에 동일한 카드를 놓는다. 흰색·회색 기본 배경으로 대체하지 않는다.
2. 테두리 밝기만 달리한 표본을 만든다. 테두리 두께·불투명도·카드 면·그림자 등 다른 조건은 고정한다.
3. 각 테두리가 배경과 구분되는지 실제 이미지 위에서 확인하고, 관찰할 점을 적는다.

> 사용자: D로 갈게.
>
> 에이전트: 확정: 테두리 밝기 = D · #888888

### 배경 조건이 한 장이 아니라 범위인 경우

사용자가 특정 이미지 대신 `황혼 시간대`를 조건으로 주면, 지침은 그 범위의 2~3개 지점에 같은 표본을 놓도록 한다. 예를 들어 해 지기 전 주황, 푸른 시간대, 해가 넘어간 뒤 남보라 배경이다. 각 배경마다 A–E 전체를 놓는다. A는 주황 배경, B는 푸른 배경에만 놓는 식으로 후보마다 배경을 달리하면 테두리 값과 배경 중 무엇이 차이를 만들었는지 알 수 없다.

## 끝나는 지점

지정된 배경 조건에서 고른 테두리 값을 기록하고 멈춘다.

## 다른 상황과의 차이

[01의 배경 토글](01.md)은 일반적인 여러 맥락에서 값을 보는 방법이다. 여기서는 배경 자체가 사용자의 요구 조건이다. 배경이나 비교 축을 에이전트가 임의로 교체하지 않는다.
