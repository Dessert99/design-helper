# 04. 마음에 드는 후보 주변을 더 비교하고 싶은 상황

[상황 목록으로](../flows.ko.md)

## 시작 조건

그림자 블러 A–E를 이미 비교하고 있다. C는 12px이며, 사용자는 아직 어느 값도 확정하지 않았다.

## 예시 대화와 스킬 행동

> 사용자: C에서 블러를 조금 더 크게 해서 보여줘.

추가 비교 요청이므로 C를 코드에 먼저 반영하지 않는다. C의 다른 속성은 유지하고 블러만 바꾸는 표본을 바로 추가한다.

지침상 같은 작업 단위의 문자는 이어져야 한다. 기존 표본이 A–E라면 추가 표본은 F부터 시작한다. 기존 표본을 삭제하거나 A부터 다시 매기지 않는다.

**현재 구현의 한계:** 지금 엔진은 비교 구역마다 글자를 A부터 다시 매겨서, 지침대로 F부터 이어 붙이지 못한다. [상세 근거](limitations.md#추가표본문자)

### 직접 조절이 필요한 경우에만 슬라이더 추가

기본은 고정된 표본을 그리고, 더 보고 싶으면 채팅으로 요청하는 방식이다. 사용자가 직접 조절을 요청하거나 연속 변화의 경계를 확인해야 할 때만 필요한 슬라이더를 추가한다. 열 수 같은 이산적 배치에는 고정 후보를 쓴다. 슬라이더를 추가했다면 실제 속성명과 현재 값으로 표시하고 최소·중간·최대에서 동작과 새로고침 복원을 검증한다. 확인하지 못하면 슬라이더 없이 고정 표본을 그린다.

이 선택적 모드에서 사용자는 채팅 없이 범위 슬라이더로 더 작거나 큰 값 쪽으로 비교 범위를 옮길 수 있다. 후보 사이 간격을 바꾸는 조절기도 필요할 때만 둔다. 이 조작은 현재 비교 구역을 다시 그리며, 채팅으로 추가 표본을 요청해 아래에 새 구역을 붙이는 것과는 다르다.

숫자 스케일은 `스케일에 맞춤`을 해제해 기존 값 사이의 후보도 탐색할 수 있다. 예를 들어 12px와 16px 사이의 13px를 보는 식이다. 토큰 정보가 있으면 기존 스케일 밖의 후보에 변경 비용과 점선을 표시한다. 유틸리티 클래스 스케일에서는 자유값 모드가 숨겨진다.

범위를 움직이면 기존 `경계` 설명은 흐려진다. 다음 에이전트 턴에서 현재 범위를 다시 확인하고 설명을 갱신해야 한다. 이전 경계가 여전히 맞는 것처럼 보고하지 않는다.

숫자 한 축의 표본에 포커스를 두고 ↑/↓를 누르면 정해진 증감 단위만큼 조정한 후보가 뒤에 추가되고 `추가`로 표시된다. 예를 들어 단위가 1px이면 12px에서 ↑를 눌러 13px 후보를 추가할 수 있다. 스케일 밖의 값을 확정했다면 그 사실을 메모에 함께 남긴다. 문자가 가리키는 값은 사용자 탭의 현재 표본에서 확인한다.

## 끝나는 지점

보완한 시안이 준비되면 기존 비교 탭과 브라우저 창을 앞으로 가져와 수정 구역을 보여준다. 닫혀 있으면 같은 시트 URL을 다시 연다. 이 비교 화면을 띄우는 데까지가 이 흐름이다. 확정은 사용자가 직접 골라야 한다.
