# 08. 장식을 제외하고 페이지의 배치와 구조를 비교하는 상황

[상황 목록으로](../flows.ko.md)

## 시작 조건

기존 페이지에 왼쪽 사이드바와 본문이 있다. 사용자는 사이드바 위치와 내용 순서는 유지하고 **사이드바 폭**을 비교하려 한다. 예시의 프로젝트 폭 스케일은 A 200px · B 224px · C 248px · D 272px · E 296px로 가정한다.

## 예시 대화와 스킬 행동

> 사용자: 사이드바 위치는 그대로 두고 폭을 비교해줘. 본문이 얼마나 남는지 보고 싶어.

1. 실제 페이지의 구조와 콘텐츠 양을 확인한다. 사이드바와 본문 사이의 간격, 전체 페이지 폭도 비교 조건으로 맞춘다.
2. 색·타이포 장식·그림자·라운드를 걷어내고 흰 바탕의 무채색 블록으로 그린다. 블록에는 `네비`, `사이드바`, `본문` 같은 역할을 표시한다.
3. 사이드바 폭만 다르게 한 표본을 제공한다. 블록의 명암으로 위계를 표시하며, 위치와 내용 순서는 유지한다.
4. 프로젝트에서 레이아웃이 달라지는 화면 폭(브레이크포인트)을 확인해 같은 A–E를 비교한다. 실제 페이지와 비슷한 수의 메뉴·본문·카드 블록을 넣어, 사이드바가 넓어졌을 때 본문 공간이 얼마나 줄어드는지 볼 수 있게 한다.

> 사용자: C 폭으로 갈게.
>
> 에이전트: 확정: 사이드바 폭 = C · 248px

## 끝나는 지점

사이드바 폭을 기록한다. 페이지의 색이나 모서리 디자인을 이어서 정하지 않는다.

## 다른 상황과의 차이

[01](01.md)은 기존 컴포넌트의 외관을 유지하며 속성 하나를 비교한다. 여기서는 구조 판단에 영향을 주는 장식을 제거한다. 색·그림자 같은 외관의 비교는 별도 주문이다.
